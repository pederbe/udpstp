# About

udpstp measures network-path capacity, loss and delay. Use it to check access lines and circuits, compare paths, or collect JSON results for your measurement tools.

It implements the UDP Speed Test Protocol in [RFC 9946](https://www.rfc-editor.org/rfc/rfc9946) and the IP-Layer Capacity method in [RFC 9097](https://www.rfc-editor.org/rfc/rfc9097). It works with [OB-UDPST](https://github.com/BroadbandForum/obudpst) key files and JSON output.
