# About

udpstp is a Rust implementation of UDPSTP, the UDP Speed Test Protocol of [RFC 9946](https://www.rfc-editor.org/rfc/rfc9946), which measures the Maximum IP-Layer Capacity that [RFC 9097](https://www.rfc-editor.org/rfc/rfc9097) defines. It is an independent implementation: it is not affiliated with the IETF or the Broadband Forum, and it interoperates with [OB-UDPST](https://github.com/BroadbandForum/obudpst), the Broadband Forum's open-source implementation.

## This site

This site is built from the repository's Markdown at each release: the guides, the reference pages generated from the binary and its sources, and the conformance pages generated from the same checks that run before every commit. It sets no cookies, runs no analytics and loads nothing from other sites. Every page is also available as Markdown at the same address with `.md`, and [llms.txt](https://udpstp.com/llms.txt) lists them all.

The headings use a subset of IBM Plex Sans Condensed Bold, renamed "udpstp Display" as its licence, the [SIL Open Font License 1.1](https://udpstp.com/fonts/OFL.txt), requires of a modified version.
