# Contributing

Help improve udpstp with bug reports, interoperability reports, documentation
or code changes. The repository's [contribution guide](../../CONTRIBUTING.md)
explains how to build, select checks and prepare a pull request.

For a protocol change, read the [architecture](../../ARCHITECTURE.md),
[glossary](../../GLOSSARY.md) and relevant
[design decisions](https://github.com/pederbe/udpstp/tree/main/docs/adr).

Report vulnerabilities through the [private security reporting route](../../SECURITY.md).
