Network capacity testing in Rust

Measure the capacity your network really delivers.

Check a circuit, compare network paths or investigate a change in performance. Measure Maximum IP-Layer Capacity, loss and delay together, then read the results in your terminal or collect JSON.

Run udpstp at both ends of a path and measure in either direction. It implements the UDP Speed Test Protocol in RFC 9946 and the IP-layer capacity method in RFC 9097.

Install

Try udpstp

Choose your platform, install udpstp, and connect to a Server for your first Test.

Linux and macOS

curl -fsSL https://udpstp.com/install.sh | sh

Installs the latest release into ~/.local/bin. Run it again to update.

Homebrew

brew install pederbe/tap/udpstp

For macOS and Linux. Updates arrive with brew upgrade.

Debian and Ubuntu

curl -fsSL https://packages.udpstp.com/udpstp.gpg | sudo tee /usr/share/keyrings/udpstp.gpg >/dev/null && echo "deb [signed-by=/usr/share/keyrings/udpstp.gpg] https://packages.udpstp.com/apt stable main" | sudo tee /etc/apt/sources.list.d/udpstp.list && sudo apt update && sudo apt install udpstp

Adds the signed apt repository, with updates through apt upgrade and the Server's systemd unit. Debian 10, Ubuntu 20.04 and newer.

Fedora, RHEL and similar

sudo curl -fsSLo /etc/yum.repos.d/udpstp.repo https://packages.udpstp.com/udpstp.repo && sudo dnf install udpstp

Adds the signed dnf repository, with updates through dnf upgrade and the Server's systemd unit. RHEL 8, Fedora and newer.

Windows PowerShell

irm https://udpstp.com/install.ps1 | iex

Installs the latest release into your account and adds it to your PATH. WinGet catalog approval is pending.

Cargo

cargo install --locked udpstp

Builds from source with Rust 1.98 or later. With cargo-binstall, cargo binstall udpstp fetches the release binary.

Built for repeatable measurement

Why udpstp

Use it for a quick circuit check, repeatable path comparisons or automated measurement.

  • 01

    See the whole Test

    Follow capacity, loss and delay throughout the measurement. The interval results help you see when a path changes under load.

  • 02

    Authenticated by default

    Control who can measure against your Server. Tests and Status PDUs are authenticated, keys stay off the command line, and Fixed-Rate Tests require an Operator Key.

  • 03

    Ready for your tools

    Read compact results in your terminal or export JSON. Use the Rust libraries to add protocol support to your own application.

  • 04

    Works with OB-UDPST

    Bring udpstp into an existing setup with OB-UDPST key files and compatible JSON output. Explore the interoperability checks for the two implementations.

Every term, defined

RFC 9946 and RFC 9097

Follow the measurement method

udpstp uses the published IP-layer capacity method. The results guide explains the numbers, and the protocol documentation connects the implementation to the RFCs.

RFC conformance details
Requirements proven by tests
@REQ_TESTED@ of @REQ_TOTAL@
Operational Requirements
@REQ_OPERATIONAL@
Not-applicable Requirements
@REQ_NOT_APPLICABLE@

Tested Requirements have proving tests. Operational Requirements concern deployment or use. Not-applicable Requirements concern other implementations or roles. A Requirement with a Deviation has a recorded departure from the RFC.

Requirements by RFC section
SectionRequirementsTestedDeviationOperationalNot applicable

Read the reasons

@RECORDS@ Conformance Records, grouped by what they explain.

Deviations
@DEVIATIONS@ recorded departures from Requirements, each with its reason.
Interpretations
@INTERPRETATIONS@ readings of ambiguous Requirements or choices the RFC leaves open.
OB-UDPST Differences
@OBUDPST_DIFFERENCES@ differences from OB-UDPST where udpstp conforms to the RFC.
