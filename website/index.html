A Rust implementation of UDPSTP Version @VERSION@*

Measure the capacity your network really delivers.

Get the capacity number and the evidence behind it. Find Maximum IP-Layer Capacity, follow loss and delay throughout a Test, and bring structured results into your own tools.

For investigating a network path or building a measurement platform. udpstp puts the metric of RFC 9097 and the UDP Speed Test Protocol (RFC 9946) in a memory-safe Rust tool with authenticated Tests.

Install

Try udpstp

Choose your platform, install udpstp, and connect to a Server for your first Test.

Linux and macOS

curl -fsSL https://udpstp.com/install.sh | sh

Installs the latest release into ~/.local/bin after checking its checksum. Runs on x86_64, aarch64 and armv7, from glibc 2.28 to Alpine and routers.

Homebrew

brew install pederbe/tap/udpstp

For macOS and Linux. Updates arrive with brew upgrade.

Debian and Ubuntu

curl -fsSL https://packages.udpstp.com/udpstp.gpg | sudo tee /usr/share/keyrings/udpstp.gpg >/dev/null && echo "deb [signed-by=/usr/share/keyrings/udpstp.gpg] https://packages.udpstp.com/apt stable main" | sudo tee /etc/apt/sources.list.d/udpstp.list && sudo apt update && sudo apt install udpstp

Adds the signed apt repository, with updates through apt upgrade and the Server's systemd unit. Debian 10, Ubuntu 20.04 and newer.

Fedora, RHEL and similar

sudo curl -fsSLo /etc/yum.repos.d/udpstp.repo https://packages.udpstp.com/udpstp.repo && sudo dnf install udpstp

Adds the signed dnf repository, with updates through dnf upgrade and the Server's systemd unit. RHEL 8, Fedora and newer.

Windows PowerShell

irm https://udpstp.com/install.ps1 | iex

Installs the latest release after checking its checksum, and adds it to your PATH. Or use winget install pederbe.udpstp.

Cargo

cargo install --locked udpstp

Builds from source with Rust 1.98 or later. With cargo-binstall, cargo binstall udpstp fetches the release binary.

Built for repeatable measurement

Why udpstp

Build measurements on an open standard and results you can verify. For Operators, Consumers and the platforms that serve them.

  • 01

    Traced to the RFCs

    Follow the method from the standard to the code. Each of the @REQ_TOTAL@ Requirements has an ID, with proving tests or a recorded reason.

  • 02

    Authenticated by default

    Control who can measure against your Server. Tests and Status PDUs are authenticated, keys stay off the command line, and Fixed-Rate Tests require an Operator Key.

  • 03

    Memory-safe Rust

    It parses untrusted network input safely. udpstp's own crates forbid unsafe, from the PDU parsers to the Data Phase Engine.

  • 04

    Works with OB-UDPST

    Bring udpstp into an existing setup. It reads OB-UDPST key files, writes compatible JSON, and is tested against OB-UDPST in both directions through a shaped bottleneck.

Know what the result means

Measure at the IP layer

A TCP-based speed test measures what its connections' congestion control achieves. UDPSTP measures what the IP layer delivers.

Different methods answer different questions
AspectTypical TCP-based speed testudpstp
What it measuresTCP-basedThe goodput TCP's congestion control reaches, headers excludedudpstpIP-Layer Capacity, headers included, as RFC 9097 defines it
How the rate is foundTCP-basedThe sender's congestion control, which differs by operating system and algorithmudpstpA Load Rate Adjustment Algorithm the RFC specifies, fed loss and delay variation every Trial Interval
LossTCP-basedHidden by retransmissionudpstpMeasured: a Loss Ratio for every Sub-Interval, with delay variation and RTT
The resultTCP-basedUsually one average over the testudpstpEvery Sub-Interval, and the maximum that meets a stated Performance Criterion
The methodTCP-basedDefined by each serviceudpstpIETF Standards Track: the metric of RFC 9097 and the protocol of RFC 9946, with implementations that interoperate
