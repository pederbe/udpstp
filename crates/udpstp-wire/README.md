# udpstp-wire

The PDU layouts and codecs of the UDP Speed Test Protocol ([RFC 9946](https://www.rfc-editor.org/rfc/rfc9946)): Setup, Activation, Null Request, Load and Status PDUs, their authentication digests and the header checksum. It decodes what arrives and leaves validity to the protocol layer, [`udpstp-core`](https://crates.io/crates/udpstp-core).

Part of [udpstp](https://github.com/pederbe/udpstp). **Pre-release:** the API will change before 1.0.
