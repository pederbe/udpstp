# Triage labels

These labels describe the state of an issue in the project tracker.

| Label | Meaning |
|---|---|
| `needs-triage` | Awaiting evaluation |
| `needs-info` | More information is needed from the reporter |
| `ready` | Fully specified and ready for implementation |
| `needs-maintainer` | Needs a maintainer's decision or hands-on work |
| `wontfix` | The project does not plan to address it |

Labels describe the issue rather than a contributor's local tools. Check existing discussion and assignments before starting work.
