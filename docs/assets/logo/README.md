# The udpstp logo

The mark is the ceiling: the sending rate steps up to the capacity the Test finds. It uses palette D, the site's colours.

| File | Use |
|---|---|
| `udpstp-mark-dark.svg` | The mark on dark backgrounds: blue #38BDF8, red #FB7185. |
| `udpstp-mark-light.svg` | The mark on light backgrounds: deeper blue #0284C7 and red #E11D48, so it keeps 3:1 contrast on white. |
| `udpstp-icon.svg` | The same mark on a graphite tile, where a square icon is needed: favicon, app icon, social image. |

There is one mark: the icon is the mark on a tile, never a second design. The wordmark is the mark beside "udpstp" set in the site's monospace face, composed in HTML. PNG favicons and the 512 px icon are rendered from these SVGs by the site build.
